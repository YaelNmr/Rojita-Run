## 📖 The Game Concept

In **Rojita Run**, you control "Rojita", a brave apple who refuses to become dessert. Players must survive a chaotic kitchen by dodging dynamic flying hazards like knives, peelers, and blenders. The main goal is simple: survive as long as possible and rack up a high score!

### Key Features Implemented:
* **Persistent High-Score System:** Learned how to handle local data saving and loading in Godot.
* **Dynamic Object Spawning:** Randomly generated flying kitchen obstacles with increasing difficulty.
* **Simple Controls:** Built using just three main keys (`Spacebar` to jump, `Enter` to pause, `Esc` for the menu) to ensure tight and responsive gameplay.
* **Catchy Audio Integration:** Implemented background music and sound cues for a more immersive experience.
